# 音乐创作参考笔记

这里公开附带天籁项目在音乐创作、编曲、演奏表达与听觉评价方面整理的一份创作
参考。它面向人类创作者和参与创作的 AI Agent，帮助把“想要什么感觉”进一步拆成
可讨论、可编辑、可试听和可复盘的判断。

这份材料是**非规范性的创作参考**：

- 不属于引擎、Schema、MCP 或发布流程必须遵守的技术合同；
- 不替创作者决定旋律、风格和审美，也不承诺照表执行就一定“好听”；
- 是否采纳完全由创作者决定；不遵守不会触发项目处罚、许可失效或功能限制；
- 指标用于发现问题和组织证据，人耳对具体作品保留最终判断；
- 可以随实践、听审和社区反馈继续修订，不以当前版本冒充普遍定律。

材料由项目作者留存并纳入天籁，其中部分研究与整理使用了 AI 辅助。文中若引用
第三方论文、标准、网站、产品或其他材料，其权利与许可仍归各自权利人；这里的
文本许可不扩大任何第三方授权，也不表示天籁为相关来源背书。

## 当前笔记

1. [天籁音乐宪法 v0.1](天籁音乐宪法-v0.1.md)

   用分层“法域”组织创作判断：先写单曲承诺，再按作品激活旋律、律动、和声、
   音色、叙事等规则，最后通过试听、例外登记和版本比较复盘。它是一套选择与

## 推荐用法

1. 创作前先写清作品的身份、情绪轨迹、主要角色、禁区和预期听众；
2. 只选择当前作品真正相关的少量原则，不把清单机械地全部打开；
3. 将原则落实为 score、roster、演奏参数或制作参数中的明确改动；
4. 保存改动前后候选并进行 A/B，记录哪条判断有效、哪条需要例外；
5. 把反复出现且能复现的经验再整理成后续版本，而不是用一次偶然听感改写通则。
