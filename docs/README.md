# 文档

这里汇总天籁 `1.1.0` 随源码包提供的用户与集成说明。运行环境、乐器与资源
状态以环境诊断命令 `tianlai-doctor` 的当次结果为准。

## 快速开始

- [Windows 最小启动](Windows最小启动.md)：创建独立虚拟环境、运行环境诊断并生成
  第一份不依赖外部采样的 WAV。
- [Windows 安装与巡检](Windows安装与巡检.md)：恢复可选音源、查看资源计划并
  处理常见安装问题。
- [Linux / WSL 快速开始](Linux快速开始.md)：Bash 入口、支持范围、MCP 配置与
  外部采样安装和恢复。
- [macOS 快速开始](macOS快速开始.md)：Apple Silicon / Intel 原生环境、portable
  门禁、MCP 配置与跨平台资源恢复边界。
- [从乐谱到第二次渲染](从乐谱到第二次渲染.md)：从 MIDI/MusicXML 导入、明确
  配器、首次渲染、按秒定位、修改到 A/B 比较的完整流程。
- [渲染后自检](渲染后自检.md)：最终 PCM 的严格完整性门、True Peak/LUFS
  测量、风险复核与人工听审边界。
- [Score v2：精确、可迁移的作品语义](score-v2.md)：有理时间、稳定身份、
  v1 迁移 bundle，以及受限 direct-v2 正式渲染与 Candidate v3 边界。
- [Realization v1](realization-v1.md)：与 score Hash 绑定的可选逐音及连续
  演奏控制，以及量化、近似和 resolved evidence 合同。

Windows 最短入口：

```cmd
安装运行环境.cmd
```

Linux / WSL 最短入口：

```bash
bash ./bootstrap_linux.sh
```

macOS 最短入口：

```bash
bash ./bootstrap_macos.sh
```

三个入口都会创建当前平台自己的 `.venv`、运行环境诊断，并使用参考振荡器完成首次
出声。虚拟环境不得跨 Windows、Linux / WSL、macOS 或 CPU 架构共用。

## AI 与 MCP

- [MCP 接口](MCP.md)：当前工具、stdio 配置、输入根权限、显式配器、不可变候选
  和缓存边界。
- [可选创作工作流](创作工作流.md)：作品宪章、分层复查、证据绑定、受管渲染、
  有界迭代与“不保证好听”的诚信边界。

CLI 与 MCP 使用同一套乐谱、配器、渲染和候选合同。Agent 可以读取合同、提出
修改并执行已确认的计划，但不会自动取得整机文件访问、选乐器或替代人工审美的
权限。

## 创作参考

- [天籁音乐宪法 v0.2](音乐创作参考笔记/天籁音乐宪法-v0.2.md)：面向人类创作者
  与 AI Agent 的非规范性创作原则；保护萌发、相因、成境与多世界并存，且不要求
  微小声音先为自己的存在辩护。宪法文本采用 CC BY 4.0，项目代码仍为 Apache-2.0。

## 能力与限制

- [当前能力与限制](当前状态.md)：平台支持、声音入口、资源恢复、渲染能力和
  已知边界。
- [乐器索引](../乐器/README.md)：103 个声音入口、资源类型和质量状态。

`quality_tier=formal` 表示当前绑定版本完成了单乐器、单音色独立试听，不等于
所有音域、力度、奏法、组合或作品均已获得专家认可。最终作品仍应实际试听。

## 音源、许可与输出

- [音源许可政策](音源许可政策.md)：第三方资源准入、隔离、署名与再分发边界。
- [VPO 音源许可与安装说明](VPO音源许可与安装说明.md)：VPO 官方安装方式、
  固定版本和混合许可边界。
- [输出权利说明](../OUTPUT_RIGHTS.md)：区分项目代码、第三方采样、输入作品和
  最终音频。
- [项目名称与标识](../TRADEMARKS.md)：二次分发时的名称与署名规则。

源码包不携带大型第三方采样。安装后的实际资源状态以环境诊断结果为准，发布音乐前
还应核对对应的 `许可与署名.json/.txt`、输入作品权利和上游资源条款。

## 本地数据目录

- [乐谱目录](../乐谱/README.md)：使用者自己的谱面、score 修订和 roster。
- [音源目录](../音源/README.md)：大型运行资源、下载缓存和安装回执。
- [输出目录](../output/README.md)：候选、分轨、作品、诊断与缓存。

这些目录各有独立生命周期；不要把虚拟环境、大型音源、私人乐谱或渲染缓存直接
加入源码分发。
