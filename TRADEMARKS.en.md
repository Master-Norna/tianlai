This statement is intended to reduce confusion about origin in open-source
redistribution. It does not alter the rights to use, modify, and redistribute

“Tianlai” is a registered trademark in any jurisdiction.

## Permitted descriptive use

- Truthfully state that software is “based on Tianlai,” “compatible with
  Tianlai,” or “derived from Tianlai,” and link to the original project.
- Refer to `天籁`, `Tianlai`, and the author `Nor.na` while preserving accurate
  origin information.
- Redistribute original or modified code under Apache-2.0 while retaining
  `LICENSE`, `NOTICE`, and applicable third-party license materials.

## Avoid confusion with official project status

A substantially modified fork, repackaged distribution, or independent service
should identify itself prominently as a third-party version. Avoid names,
icons, accounts, or domains that would lead an ordinary user to believe it is
maintained, certified, sponsored, or released by the original project. A name
such as “a Tianlai-based fork” is descriptive; naming a third-party version only
“Official Tianlai,” “Tianlai Official,” or making an equivalent implication is
not.

Section 6 of Apache-2.0 does not itself grant permission to use a licensor's
trade names, trademarks, service marks, or product names, except as required
for reasonable and customary description of the work's origin and reproduction
of the `NOTICE` file. Modified files must also be marked prominently as changed
as required by the license.

The project has not authorized any third party to release software, resource
packages, or hosted services as “official Tianlai.” The latest statement in the
original project repository is authoritative for project names, accounts, and
identity.
