# 管弦重击

基于 Virtual Playing Orchestra 3.3 真实采样构造的分层管弦重击 `formal`。它不是 GM Orchestra Hit，也不是合成器替代：每次触发会把同一实音乐高的真实弦乐重音和铜管重音，与固定的大鼓 D2、Crash 镲 F♯4 叠加。

## 当前能力

- 弦乐四声部与铜管四声部在共同范围 D1–C6（MIDI 26–84）按上游键位交叉淡化；
- 弦乐重音 182 个区域、铜管重音 155 个区域；铜管拆分为 79 个短起音区域与 76 个循环持续区域；
- 大鼓 D2 为 2RR × 2 个交叉淡化力度层；Crash 镲 F♯4 为 2RR × 2 个离散力度层；
- 一次事件按固定门限释放有音高持续层，打击乐按原录音 one-shot 衰减；外部音符长度不会意外截断重击；
- 140 个稳定持续根采样经过谐波约束 FFT 校准：中位偏差 `-0.081554 cents`，最大原始偏差 `22.954514 cents`；短噪声起音不做不可靠 FFT 校准；
- 4 份 SFZ 共引用 345 个区域、278 个去重 WAV；确定性渲染保留真实 Round Robin 与力度层。

## 它为什么仍放在“电子乐器”分类

“管弦重击”在这里是制作型组合音色/效果器，而不是一种可由单个演奏者演奏的原声乐器。分类表示用途，不表示底层用电子波形冒充；底层四组素材全部是真实乐器录音。

## 使用

```powershell
.\.venv\Scripts\python.exe -m tianlai render `
  --instrument 乐器/电子乐器/管弦重击/乐器.json `
  --events examples/管弦重击_奏法.events.json `
  --output output/管弦重击_奏法_candidate.wav
```

## 单音色 formal 不代表的能力

- 这是程序化叠层的同音 tutti，不是录音棚里一次录下、相位天然一致的专用 Orchestra Hit，也不是预录大/小三和弦；
- 大鼓和镲固定音高，不随弦铜管移调；没有房间多麦位、独立释音、更多镲/鼓选择；
- 当前绑定版本的单音色试听已通过，因此为 `formal`；分层平衡、冲击感与协奏盲听仍待审。
