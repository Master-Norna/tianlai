# 扫频铺底

默认 `sweep_pad`（引擎 `1.0.0`，`formal`）把六声部带限锯齿、正弦与固定种子宽带噪声送入高谐振 TPT 低通；约 0.087 Hz 的深度滤波 LFO 跨越多个八度，形成真正的长周期扫频而非静态音色改名。

- 校准音域：MIDI 24–108，硬边界。
- 控制：`modulation` 明显增加扫频与颤音深度，另支持力度、`expression` 和踏板。
- 固定种子：`3678794411`。
- 试听谱例：`examples/扫频铺底_程序合成.events.json`。
- 状态：长周期运动与共振峰值仍待人工试听。

显式应急回退：GeneralUser GS bank `0` / program `95`；不会静默触发。
