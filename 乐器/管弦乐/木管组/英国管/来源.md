# 英国管音源来源

本入口使用 **Virtual Playing Orchestra Standard Orchestra 3.3（2026-06-27）** 与 **Wave Files 3.2（2026-06-27）**。

- 整理与映射：Paul Battersby，Virtual Playing Orchestra，<https://virtualplaying.com/virtual-playing-orchestra/>
- 实际采样子库：`libs/SSO/Samples/Cor Anglais/`
- 上游采样：Sonatina Symphonic Orchestra，Creative Commons Sampling Plus 1.0；混合库条件以 `Documentation/license.htm` 为准
- 采用的 SFZ：`english-horn-SOLO-normal-mod-wheel.sfz`、`english-horn-SOLO-sustain.sfz`、`english-horn-SOLO-staccato.sfz`、`english-horn-SOLO-accent.sfz`

VPO 说明允许使用该库制作音乐。重新打包、修改或分发 SFZ/WAV 本体时仍须遵守 Sampling Plus 1.0、署名和 VPO 混合库说明；轻量源码包不携带音频资产。

精确 4 个 SFZ Hash、9 个 WAV 聚合 Hash、许可与版本证据 Hash 见 [资源核验.json](资源核验.json)，可由 `核验资源.py` 复算。GeneralUser GS / TimGM 仅作为显式故障后备。
