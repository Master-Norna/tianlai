# 竖笛（formal）

本入口使用 VCSL 1.2.2-RC 的巴洛克高音竖笛实录。默认 `sustain`
不再直接读取录音室立体声文件，而是读取离线生成的相位、声像和稳态响度统一版本；
`staccato` 仍使用原始 VCSL 断奏映射。运行时不做音频预处理，也没有通用
SoundFont 静默回退。

## 音源与许可

- 上游：sgossner/VCSL，版本 1.2.2-RC；
- 原始许可：CC0-1.0；
- 13 个持续音派生 WAV 同样按 CC0-1.0 使用；
- 原始文件保留在 `音源/VCSL`，脚本只写 `音源/派生/竖笛-v1`；
- 原始、派生 SFZ、采样和许可证据 Hash 见 `资源核验.json`。

## 离线派生

```powershell
.\.venv\Scripts\python.exe .\乐器\管弦乐\木管组\竖笛\预处理音源.py
```

处理配方冻结在 `预处理参数.json`，算法实现在
`tianlai/derived_samples.py`。脚本逐文件核对原始 SHA-256，生成 PCM24 WAV、
`sustain.sfz` 和 `处理说明.json`；任何输入 Hash 不符都会明确失败。

13 个持续根样本执行：

1. 按配方中的整数帧偏移和极性修正左右声道；
2. 合成为双单声道，消除根样本之间游移的声像和反相抵消；
3. 以起音后 0.75–3.75 秒为稳态窗，统一到 −20 dBFS RMS；
4. E5、F♯5、A♯5、C6 仅做平滑、零相位的温和高频搁架和噪声带滚降；
5. 保持采样率、帧数、原始 SFZ offset 和音高映射不变。

## 奏法与音域

- `sustain`：派生持续音，默认奏法；
- `staccato`：原始 VCSL 独立断奏；
- 实音范围：C5–D7（MIDI 72–98）。

## 已知限制

当前资源只有一个真实力度层，没有持续音 RR，也没有循环。派生处理修复的是明显的
相位、声像、响度和高区噪声接缝，不把单层音源虚报为完整多力度音源。新的全音域
试听仍需人工复核后后续仍需独立复核。
