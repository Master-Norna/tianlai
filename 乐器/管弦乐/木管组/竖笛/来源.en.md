# Source

- Upstream project: sgossner/VCSL (Versilian Community Sample Library)
- Original URL: https://github.com/sgossner/VCSL
- Version used: 1.2.2-RC
- License: CC0-1.0
- Original resource root: `音源/VCSL`
- Derived resource root: `音源/派生/竖笛-v1`

The default sustain articulation uses offline-derived copies of 13 original VCSL root samples; staccato continues to use 12 original VCSL samples. Derivation is limited to phase/stereo-image unification, steady-state loudness calibration, and gentle spectral cleanup for four high-register root samples, and it does not overwrite or replace the original files. Processing parameters, original per-file SHA-256 values, license inheritance, and the output summary are recorded in `预处理参数.json`, `处理说明.json` in the derived directory, and `资源核验.json`, respectively.
