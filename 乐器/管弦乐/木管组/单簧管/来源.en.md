# Clarinet Sample Source

This entry point uses the solo-clarinet SFZ files from **Virtual Playing Orchestra Standard Orchestra 3.3 (2026-06-27)** with **Wave Files 3.2 (2026-06-27)**.

- Curation and mapping: Paul Battersby, Virtual Playing Orchestra, <https://virtualplaying.com/virtual-playing-orchestra/>
- Actual sample sublibrary: `libs/NoBudgetOrch/SoloClarinet/`
- Samples and original mapping: No Budget Orchestra. VPO's general license lists this source family as CC BY-SA 4.0, while the package retains the original source notes for the specific sublibrary.
- SFZ files used: `clarinet-SOLO-normal-mod-wheel.sfz`, `clarinet-SOLO-sustain.sfz`, `clarinet-SOLO-staccato.sfz`, and `clarinet-SOLO-accent.sfz`

Rendering music with the library and redistributing samples are different activities. Anyone modifying, repacking, or distributing the SFZ/WAV resources themselves must retain upstream attribution and the full license files and comply with CC BY-SA 4.0. The lightweight source release does not include these audio assets.

See [资源核验.json](资源核验.json) and `核验资源.py` for exact SHA-256 values for the 4 SFZ files, the aggregate SHA-256 for 26 deduplicated WAV files, license files, version evidence, and the reproducible algorithm. GeneralUser GS / TimGM may only be selected explicitly by the user as a failure fallback and never silently impersonate the current bound implementation.

The license status of this entry point is `grandfathered`: it only reads a pinned, complete release tree obtained by the installer from VPO's official download chain and installed unchanged. Tianlai does not mirror, split, or republish these samples. Archive hashes and the license and installation notes for the complete tree are available in [`VPO 音源许可与安装说明`](../../../../docs/VPO音源许可与安装说明.en.md).
