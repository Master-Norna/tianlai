# Flute Sample Source

The flute uses the solo-flute SFZ mappings from **Virtual Playing Orchestra 3.3**, with underlying recordings from **VSCO 2 Community Edition**.

- Curation and maintenance: Paul Battersby
- VPO upstream: https://virtualplaying.com/virtual-playing-orchestra/
- Original recordings: Versilian Studios VSCO 2 Community Edition
- Wave package: Virtual Playing Orchestra 3.2 Wave Files
- Mappings: Virtual Playing Orchestra 3.3 Standard SFZ Scripts
- Articulations: sustain, normal-mod-wheel, staccato, accent

VPO's license notice permits commercial use of rendered musical works; VSCO 2 Community Edition is marked CC0 in this library. Anyone repacking or distributing the samples themselves should still retain the upstream documentation and defer to the latest license text.

Audio assets are stored under the project-root `音源/` directory and are not included in source control or the lightweight source package.
