# 旋律通鼓(formal)

GM 旋律通鼓 = 按音阶排布的通鼓。本实现用 VCSL 两只真实通鼓的鼓棒击
采样(各 3 力度层 × 2 RR),先用 FFT 实测两鼓膜面基频作为根音,再把
低鼓映射到 C2(36)-F#2(42)、高鼓映射到
G2(43)-C#3(49),谱面音高经重采样
移调得到半音阶。实现 `tianlai/melodic_toms.py`,无通用 SoundFont 回退。

## 来源与许可

- 上游:sgossner/VCSL (Versilian Community Sample Library)
- 版本:1.2.2-RC,许可:CC0-1.0
- 12 个采样逐文件 SHA-256 见 [`资源核验.json`](资源核验.json)

## 调音

实测根音:低鼓 41.27(≈F2),
高鼓 44.25(≈G#2);鼓内采样基频散布见
[`音准校准.json`](音准校准.json)。根音来自测量,谱面音高按构造准确。

## 力度与 RR

每鼓 3 力度层(0-65 / 66-99 / 100-127)× 2 RR,保持上游区间。

## 试听

固定事件:`examples/旋律通鼓_奏法.events.json`;渲染 7.31 s,
峰值 0.420013,RMS 0.024074,削波 0;
WAV SHA-256 `368f0c7301cf…`。

## 已知限制

只有两只实鼓,远离根音的键靠重采样移调,音色随距离渐失真实感;
无软槌/边击层。当前绑定版本已通过单音色试听并标为 formal；协奏、完整奏法与实际曲目仍未测试。
