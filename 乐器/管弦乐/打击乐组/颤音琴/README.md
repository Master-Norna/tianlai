# 颤音琴

本入口已迁移为 VCSL `1.2.2-RC` 的严格 CC0 专用多采样
`formal`，不再依赖 VPO/Iowa 的历史保留许可，也不再把相邻根音冒充 RR。

## 真实素材

- 软槌：11 个实录根音 × 2 个真实录音力度层；
- 硬槌：11 个实录根音 × 2 个真实录音力度层；
- 弓奏：6 个实录根音 × 1 层；
- 共 50 份立体声录音，真实 RR 数为 0；
- 软槌、硬槌范围 F3–F6（MIDI 53–89），弓奏范围 A3–F6
  （MIDI 57–89）。

## 奏法

- `damped` / `open`：软槌，前者在松键时使用 350 ms 工程制音；
- `hard_damped` / `hard_open`：硬槌，同样区分工程制音与自然尾音；
- `bowed`：独立弓奏录音。

50/50 录音使用实测音高作运行时校准；上游 SFZ 与 WAV 均保持不变。固定试听、
资源 Hash 和音准数据分别见 `试听核验.json`、`资源核验.json` 和
`音准校准.json`。

```powershell
.\.venv\Scripts\python.exe 乐器/管弦乐/打击乐组/颤音琴/核验资源.py
.\.venv\Scripts\python.exe 乐器/管弦乐/打击乐组/颤音琴/校准音准.py
```

## 诚实限制

当前没有同音 RR、电机转速/深度控制、独立踏板噪声或多麦位；`damped` 是项目
释放包络，并非独立制音录音。当前绑定版本的单音色试听已通过，因此为 `formal`；独立制音与协奏盲听仍待更细验收。
