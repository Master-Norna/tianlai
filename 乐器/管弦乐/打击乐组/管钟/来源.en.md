# Tubular Bells Sample Source

- Upstream project: sgossner/VCSL (Versilian Community Sample Library)
- Project URL: https://github.com/sgossner/VCSL
- Pinned release page: https://github.com/sgossner/VCSL/releases/tag/v1.2.2-RC
- Version used: `1.2.2-RC`
- Release commit: `b6e6ac82d22248edee98a0bde185eb9ef6d439ad`
- License: `CC0-1.0`
- License evidence: sample-root `README.md`, SHA-256 `e360f24c120c9ad734cc8508695e09a61ddc4cae5a59c6c9af33fe501b6c9a5b`

Only the following are used:

- `Idiophones/Struck Idiophones/Tubular Bells 2.sfz`, SHA-256 `9ce2237fe3d23921500c6e537bb03b563b2a29dc7f9ba31c6b72bc49631208c6`.
- The 22 WAV files under `Idiophones/Struck Idiophones/Tubular Bells 2/` referenced by that SFZ, totaling 75,496,208 bytes.
- Aggregate collection SHA-256 for the 22 WAV files: `f35617d893237a552b722d8471d9f73790cc75a12dcf615a6b80db4dd966a3cc`.

Aggregation algorithm: sort by POSIX path relative to the VCSL root, concatenate the original template `<小写文件 SHA-256><两个空格><路径>\n`—lowercase file hash, two spaces, and path—for each item, then compute SHA-256 over the UTF-8 bytes. See [资源核验.json](资源核验.json) for every WAV hash, format, mapping statistics, and audio-integrity metric.

Neither `Tubular Bells 1` nor `Tubular Bells 3 Legacy` is mixed in. The former has tails truncated at file boundaries in several places and clear lineage overlap with the original isolated source; the latter is single-velocity, lossy Vorbis legacy material. The three sets are not misrepresented as velocity layers or round robins.

The current local VCSL tree is an existing pinned project resource; no instrument-specific non-overwriting installer may be claimed. If the lightweight release excludes `音源/`, users must separately restore VCSL `v1.2.2-RC` resources that match `资源核验.json` exactly. The project's zeroing of the two incorrect SFZ `offset` values occurs only at the loading layer and does not rewrite upstream SFZ or WAV files.
