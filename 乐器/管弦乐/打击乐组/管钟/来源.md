# 管钟音源来源

- 上游项目：sgossner/VCSL（Versilian Community Sample Library）
- 项目地址：https://github.com/sgossner/VCSL
- 固定发布页：https://github.com/sgossner/VCSL/releases/tag/v1.2.2-RC
- 采用版本：`1.2.2-RC`
- 发布提交：`b6e6ac82d22248edee98a0bde185eb9ef6d439ad`
- 许可：`CC0-1.0`
- 许可证据：音源根目录 `README.md`，SHA-256
  `e360f24c120c9ad734cc8508695e09a61ddc4cae5a59c6c9af33fe501b6c9a5b`

实际只采用：

- `Idiophones/Struck Idiophones/Tubular Bells 2.sfz`，SHA-256
  `9ce2237fe3d23921500c6e537bb03b563b2a29dc7f9ba31c6b72bc49631208c6`；
- `Idiophones/Struck Idiophones/Tubular Bells 2/` 下由该 SFZ 引用的 22 个
  WAV，共 75,496,208 字节；
- 22 个 WAV 的集合聚合 SHA-256
  `f35617d893237a552b722d8471d9f73790cc75a12dcf615a6b80db4dd966a3cc`。

聚合算法为：按 VCSL 根目录相对 POSIX 路径排序，逐项拼接
`<小写文件 SHA-256><两个空格><路径>\n`，再对 UTF-8 字节求 SHA-256。
逐 WAV Hash、格式、映射统计和音频完整性指标见
[资源核验.json](资源核验.json)。

未混入 `Tubular Bells 1` 或 `Tubular Bells 3 Legacy`：前者多处尾音被文件
边界截断且与原隔离音源存在明显谱系重合，后者是单力度的有损 Vorbis
Legacy 素材。也没有把三个集合伪装成力度层或 round robin。

当前本地 VCSL 是项目已有的冻结资源，不能宣称存在本乐器专属的无覆盖安装器。
轻量发布包若排除 `音源/`，运行者需单独恢复与 `资源核验.json` 完全一致的
VCSL `v1.2.2-RC` 资源。项目对两个错误 SFZ `offset` 的归零只发生在加载层，
没有改写上游 SFZ 或 WAV。
