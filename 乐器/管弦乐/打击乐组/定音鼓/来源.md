# 定音鼓音源来源

- 上游项目：sgossner/VCSL（Versilian Community Sample Library）
- 项目地址：https://github.com/sgossner/VCSL
- 固定发布页：https://github.com/sgossner/VCSL/releases/tag/v1.2.2-RC
- 采用版本：`1.2.2-RC`
- 发布提交：`b6e6ac82d22248edee98a0bde185eb9ef6d439ad`
- 许可：`CC0-1.0`
- 许可证据：音源根目录 `README.md`，SHA-256
  `e360f24c120c9ad734cc8508695e09a61ddc4cae5a59c6c9af33fe501b6c9a5b`

实际默认方案只采用：

- `Membranophones/Struck Membranophones/Timpani 2 - Scale.sfz`，用于
  `hit`，SHA-256
  `2e1953d4c3c79c187d312f4f93a7249f3024dbc5b4b69b8190c9d68925fb5ab4`；
- `Membranophones/Struck Membranophones/Timpani 1 - Roll.sfz`，用于
  `roll`，SHA-256
  `3ec91e9eee1d8614889380b1a5581fdc5191baaf7598eac6d3c038811dd5c1e5`；
- 两个 SFZ 引用的 64 个唯一 WAV，共 132,588,162 字节；
- 64 个 WAV 的集合聚合 SHA-256
  `d323d3c2a7587be4948bf831b4956c6e0d6fec73aceb4255a425226be8c1803a`。

聚合算法为：按 VCSL 根目录相对 POSIX 路径排序，逐项拼接
`<小写文件 SHA-256><两个空格><路径>\n`，再对 UTF-8 字节求 SHA-256。
逐 WAV Hash、格式、映射、削波、尾音、offset 与最小余量见
[资源核验.json](资源核验.json)。

候选比较还审查了 `Timpani 1 - Hit.sfz`。它与滚奏的录音一致性更好，
且同样有 3 个真实力度层和 RR2，但只有 MIDI 41–55、5 个音高组和 PCM16。
最终用更宽、更密的 PCM24 `Timpani 2 - Scale` 作为单击，同时诚实声明
两套录音间可能存在音色接缝；完整机器指标见
[VCSL候选比较.json](VCSL候选比较.json)。

没有改写上游 SFZ 或 WAV，也没有从其他许可来源混入素材。轻量发布包若排除
`音源/`，运行者需单独恢复与报告 Hash 完全一致的 VCSL 资源。
