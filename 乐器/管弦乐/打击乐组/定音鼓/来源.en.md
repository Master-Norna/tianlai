# Timpani Sample Source

- Upstream project: sgossner/VCSL (Versilian Community Sample Library)
- Project URL: https://github.com/sgossner/VCSL
- Pinned release page: https://github.com/sgossner/VCSL/releases/tag/v1.2.2-RC
- Version used: `1.2.2-RC`
- Release commit: `b6e6ac82d22248edee98a0bde185eb9ef6d439ad`
- License: `CC0-1.0`
- License evidence: sample-root `README.md`, SHA-256 `e360f24c120c9ad734cc8508695e09a61ddc4cae5a59c6c9af33fe501b6c9a5b`

The actual default configuration uses only:

- `Membranophones/Struck Membranophones/Timpani 2 - Scale.sfz` for `hit`, SHA-256 `2e1953d4c3c79c187d312f4f93a7249f3024dbc5b4b69b8190c9d68925fb5ab4`.
- `Membranophones/Struck Membranophones/Timpani 1 - Roll.sfz` for `roll`, SHA-256 `3ec91e9eee1d8614889380b1a5581fdc5191baaf7598eac6d3c038811dd5c1e5`.
- 64 unique WAV files referenced by the two SFZ files, totaling 132,588,162 bytes.
- Aggregate collection SHA-256 for the 64 WAV files: `d323d3c2a7587be4948bf831b4956c6e0d6fec73aceb4255a425226be8c1803a`.

Aggregation algorithm: sort by POSIX path relative to the VCSL root, concatenate the original template `<小写文件 SHA-256><两个空格><路径>\n`—lowercase file hash, two spaces, and path—for each item, then compute SHA-256 over the UTF-8 bytes. See [资源核验.json](资源核验.json) for every WAV hash, format, mapping, clipping, tail, offset, and minimum headroom.

Candidate comparison also reviewed `Timpani 1 - Hit.sfz`. It matches the roll recordings more consistently and likewise has 3 genuine velocity layers and RR2, but covers only MIDI 41–55 with 5 pitch groups and PCM16. The final choice uses the wider, denser PCM24 `Timpani 2 - Scale` for single hits while explicitly disclosing the possible timbral seam between the two recording sets. Complete machine metrics are in [VCSL候选比较.json](VCSL候选比较.json).

No upstream SFZ or WAV file has been rewritten, and no material from another license source has been mixed in. If the lightweight release excludes `音源/`, users must restore VCSL resources separately and report hashes exactly matching these records.
