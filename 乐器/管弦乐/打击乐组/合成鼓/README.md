# 合成鼓(formal,确定性建模)

模拟鼓机合成鼓:指数降频正弦 + 咔嗒瞬态 + 短噪声,谱面音高定基频。实现位于 `tianlai/modeled_instruments.py`(profile
`synth_drum`,引擎 1.1.0),显式种子 41034,同一事件
序列必得同一输出;不含通用 SoundFont 静默回退。

## 建模缘由(诚实声明)

该音色定义上就是程序合成,建模即正确路线。

## 来源与许可

项目自研确定性 DSP;引擎源文件 SHA-256 与全部参数见
[`资源核验.json`](资源核验.json),复算脚本 [`核验资源.py`](核验资源.py)。

## 音域

C2(36) - C6(84)

## 调音

自测校准:渲染 3 个探测音并 FFT 实测,最大误差 0.366 音分(详见 [`音准校准.json`](音准校准.json))

## 试听

固定事件:`examples/合成鼓_奏法.events.json`;
渲染 11.89 s,峰值 0.419980,
RMS 0.066693,削波 0;
WAV SHA-256 `bc487479…`。复算脚本 [`核验试听.py`](核验试听.py)。

## 已知限制

面向 GM Synth Drum 语义;非任何具体鼓机的电路仿真。当前绑定版本已通过单音色试听并标为 formal；协奏、完整奏法与实际曲目仍未测试。
