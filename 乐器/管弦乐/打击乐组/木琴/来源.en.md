# Xylophone Sample Source

This entry point is pinned to `Percussion/xylophone.sfz` from VPO **Standard Orchestra 3.3 / Wave Files 3.2 (2026-06-27)**. It comes from No Budget Orchestra and uses 30 deduplicated WAV files (15 root regions × 2 round robins) under CC BY-SA 4.0.

For convenient keyboard performance, the upstream SFZ shifts key positions down one octave. This entry accepts concert-pitch MIDI 60–108 (C4–C8) and restores that offset internally only when selecting samples. A score using traditional xylophone notation should enter C3–C7 one octave lower and let the collaboration layer add 12 semitones.

The aggregate resource SHA-256 is `f0d95fa6a3ea0fa8601cc5f69b1cf08b0e0586f88d84b6b65a4170698af64da4`. See [资源核验.json](资源核验.json) for complete license, SFZ/WAV, and version hashes.
