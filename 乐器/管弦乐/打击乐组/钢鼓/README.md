# 钢鼓(formal,确定性建模)

钢鼓模态模型:失谐倍频对拍频(±4 音分)、ping 起音、亮泛音。实现位于 `tianlai/modeled_instruments.py`(profile
`steelpan`,引擎 1.1.0),显式种子 41037,同一事件
序列必得同一输出;不含通用 SoundFont 静默回退。

## 建模缘由(诚实声明)

发声机理适合建模;真实采样对照仍是后续保真升级方向。

## 来源与许可

项目自研确定性 DSP;引擎源文件 SHA-256 与全部参数见
[`资源核验.json`](资源核验.json),复算脚本 [`核验资源.py`](核验资源.py)。

## 音域

A3(57) - F6(89)

## 调音

自测校准:渲染 3 个探测音并 FFT 实测,最大误差 0.043 音分(详见 [`音准校准.json`](音准校准.json))

## 试听

固定事件:`examples/钢鼓_奏法.events.json`;
渲染 11.89 s,峰值 0.365621,
RMS 0.068626,削波 0;
WAV SHA-256 `03c2b189…`。复算脚本 [`核验试听.py`](核验试听.py)。

## 已知限制

确定性模态模型非实录;单鼓面,无组合钢鼓乐队宽度。当前绑定版本已通过单音色试听并标为 formal；协奏、完整奏法与实际曲目仍未测试。
