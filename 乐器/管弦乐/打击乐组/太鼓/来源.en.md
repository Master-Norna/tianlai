# Source

- Implementation: project-developed deterministic physical/signal modeling (`tianlai/modeled_instruments.py`, profile `taiko`)
- Engine version: 1.1.0; see `资源核验.json` for the engine SHA-256
- Reason for modeling: no genuine sample set with a clear public license was found, so deterministic physical modeling currently fills the gap; genuine samples remain a future fidelity upgrade
- No external sample assets; the project-developed DSP implementation is released under Apache-2.0, and audio-asset licensing does not apply
