# 太鼓(formal,确定性建模)

圆膜模态太鼓模型:贝塞尔模态比 + 鼓皮拍击噪,三键位。实现位于 `tianlai/modeled_instruments.py`(profile
`taiko`,引擎 1.1.0),显式种子 41035,同一事件
序列必得同一输出;不含通用 SoundFont 静默回退。

## 建模缘由(诚实声明)

未找到有明确公开许可的真实采样,先以确定性物理建模补位;真实采样仍是后续保真升级方向。

## 来源与许可

项目自研确定性 DSP;引擎源文件 SHA-256 与全部参数见
[`资源核验.json`](资源核验.json),复算脚本 [`核验资源.py`](核验资源.py)。

## 音域

见键位映射

## 键位映射

| MIDI 键 | 内容 |
| --- | --- |
| 60 | don 中心击(82 Hz 圆膜模态) |
| 61 | 边缘击(118 Hz,高模态偏重) |
| 62 | ka 鼓边木击(短促高频) |

## 调音

太鼓为膜鸣打击,键 60/61/62 选择 don 中心击/边缘击/ka 鼓边木击,不做十二平均律校准(详见 [`音准校准.json`](音准校准.json))

## 试听

固定事件:`examples/太鼓_奏法.events.json`;
渲染 11.89 s,峰值 0.349451,
RMS 0.044988,削波 0;
WAV SHA-256 `68036221…`。复算脚本 [`核验试听.py`](核验试听.py)。

## 已知限制

确定性模态模型非实录;无连打尾音相互作用。当前绑定版本已通过单音色试听并标为 formal；协奏、完整奏法与实际曲目仍未测试。
