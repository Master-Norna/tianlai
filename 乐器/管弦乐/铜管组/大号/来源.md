# 大号音源来源

本入口使用 **Virtual Playing Orchestra Standard Orchestra 3.3（2026-06-27）** 的 `tuba-SOLO-sustain.sfz` 与 `tuba-SOLO-staccato.sfz`，配套 **Wave Files 3.2（2026-06-27）**。

- 原始采样：Mattias Westlund 的 Sonatina Symphonic Orchestra；VPO 授权文档标为 Creative Commons Sampling Plus 1.0；
- 修改与映射：Paul Battersby，Virtual Playing Orchestra；
- 上游项目：<https://virtualplaying.com/virtual-playing-orchestra/>。

上游允许使用该库制作音乐，包括商业用途。重新分发采样库时必须核对 Sampling Plus 1.0 和 VPO 混合授权、保留授权与署名；源码发布包不携带音频资产。实际采用的 2 个 SFZ、21 个去重 WAV 和版本/授权证据 Hash 见 `资源核验.json`。
