# Harp Sample Source

This entry point is pinned to `Concert Harp.sfz` and the recordings it directly references from **Versilian Community Sample Library (VCSL) 1.2.2-RC**.

- Upstream repository: <https://github.com/sgossner/VCSL>
- Pinned version: `1.2.2-RC`
- Pinned commit: `b6e6ac82d22248edee98a0bde185eb9ef6d439ad`
- SFZ: `Chordophones/Composite Chordophones/Concert Harp.sfz`
- License evidence: the repository-root `README.md` states that VCSL is released under CC0 1.0
- 45 deduplicated stereo PCM16/44.1 kHz WAV files, 76,694,972 bytes
- Aggregate SHA-256 for the sample collection: `fde6a8543ff0dac04989deb96ead10ede341e6bdae50240a123cef5bb6c497d7`

Both `Concert Harp` and `Folk Harp` in the local VCSL tree were reviewed before selection:

- Concert Harp: 45 regions, 23 recorded root notes, MIDI 28–102, maximum transposition 2 semitones.
- Folk Harp: 58 regions, 29 recorded root notes, MIDI 36–93, maximum transposition 1 semitone.

Folk Harp is sampled more densely within its own range, but it is a different, smaller instrument and lacks the low and high endpoints required of a concert harp, so it was not mixed into Concert Harp. Filename suffixes such as `f1` and `mf1` denote sample naming/velocity and must not be used to claim that round robin exists.

The upstream SFZ uses velocity crossfades for the 22 roots with two recordings. This project currently switches deterministically at the midpoint; the lowest E1 has only one recording. The original files contain no loops, and tails come directly from the recordings. Open strings and simulated damping share the same recordings; the latter is only an engineering envelope, not an independent palm-damping sample.

Of the 42 nonzero upstream offsets, only the 3744-frame offset for `KSHarp_D4_f1.wav` noticeably removes the attack. This project overrides only that offset to 0 at the manifest layer, retains the other 41 trims, and leaves the original VCSL SFZ unchanged.

Exact results for the SFZ, license evidence, every WAV file, aggregation algorithm, format, range, velocity selection, offsets, tails, and peak levels are available in [资源核验.json](资源核验.json). Large files are stored only under the project-level `音源/VCSL`; the released code package can continue to exclude the entire `音源` directory.
