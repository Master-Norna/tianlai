# 竖琴

基于 **VCSL Concert Harp** 的音乐会竖琴 `formal`。当前实际加载 45 个 CC0 立体声拨弦录音，覆盖 23 个实录根音；后端类型仍叫 `vpo_harp`，只是为兼容既有事件协议而保留的历史名字，并不代表仍在使用 VPO 音源。

## 当前语义

- 输入统一为实音；运行时严格限制在 VCSL 映射覆盖的 E1–F♯7（MIDI 28–102），不虚构未采样的物理音域端点；
- 23 个实录根音中，最低 E1 只有一份录音，其余 22 个根音各有两份不同力度的录音，因此是 45 份录音、每根最多两层，不是“三力度层”或 round-robin；
- VCSL SFZ 的力度交叉淡化目前由确定性的中点切层表示；整数 MIDI 力度 0–127 在全音域逐项检查后均恰好选中一个区域，但当前采样器还没有连续交叉淡化；
- `open` 与 `sustain` 是自然开放弦别名，使用原录音完整尾音和 30 秒松键包络；`dampened` 复用同一拨弦录音并用 350 ms 工程包络近似手掌制音；
- `sustain_pedal` 是协作层的“保持/统一制音”抽象：按下后 note-off 暂缓，松开后释放待制音弦；它**不是**真实竖琴七个变音踏板；
- 45 个录音逐文件测量音准，运行时以实测频率作为各录音根音，避免把上游 SFZ 的粗调值当成最终校准；
- 上游 42 个非零起音偏移中保留 41 个合理静音裁剪；仅覆盖 `KSHarp_D4_f1.wav` 的 3744 帧偏移，因为它会切掉主要拨弦攻击，VCSL 原始 SFZ 未被修改；
- 工程增益 `0.38`，按采样峰值与 SFZ `volume` 联合核验后保留至少 6 dB 单音余量；
- 支持 A4、小数 MIDI/Hz 音高、力度、expression、自然 WAV 尾音和确定性渲染；
- 所选 VCSL 版本、SFZ、45 个 WAV 和许可证据均以 SHA-256 冻结，许可为 CC0 1.0。

```powershell
.\.venv\Scripts\python.exe -m tianlai render `
  --instrument 乐器/管弦乐/拨弦组/竖琴/乐器.json `
  --events examples/竖琴_奏法.events.json `
  --output output/竖琴_奏法.wav
```

## 单音色 formal 的已知限制

- 不自动求解七踏板换音、重踏板/踏板滑音，也不会阻止现实踏板配置下不可同时出现的同名异音；这些应由未来协作层检查；
- 没有真实向上/向下 glissando 录音、指甲音、敲击共鸣箱、bisbigliando、泛音或独立制音采样；
- `dampened` 复用同一拨弦 WAV，以较短包络近似手掌制音；
- 没有 round-robin，重复同音不会自动轮换采样；力度交叉淡化暂为中点切层，变调仍使用线性重采样；
- 当前绑定版本的单音色试听已通过，因此为 `formal`；真实演奏者对照与协奏盲听仍待审，不会写成“100% 还原”。
