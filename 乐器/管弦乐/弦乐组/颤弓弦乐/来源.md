# 颤弓弦乐音源来源

本入口固定使用 **VPO Standard Orchestra 3.3 / Wave Files 3.2（2026-06-27）** 的 `Strings/all-strings-SEC-tremolo.sfz`。

- 上游：<https://virtualplaying.com/virtual-playing-orchestra/>
- 实际子库：No Budget Orchestra 2 的 CelloSect、SoloViolin、ViolinSect，以及 VPO `Other/Samples/Bass-Section`、`Other/Samples/Viola-Section`；
- 96 个去重 WAV，84,871,254 bytes，聚合 SHA-256 `b93eb3dc…1389354`；
- CelloSect/ViolinSect 文件标为 CC BY-SA 4.0；SoloViolin 许可文件列出多个 Freesound 来源及 Sampling+、CC0、CC BY、CC BY-NC 等条款；`Other` 要求回到具体 SFZ/来源说明核对。

VPO 总许可说明允许用本库创作音乐（含商业用途），但音源再分发必须逐来源履约、署名并保留许可。考虑到 SoloViolin 混合来源，本项目不在源码发布包内重新分发这些 WAV。

SFZ、样本集合、许可与版本证据的精确 Hash 见 [资源核验.json](资源核验.json)。

本入口的许可状态为 `grandfathered`：只读取安装器从 VPO 官方下载链取得并原样
安装的固定完整发行树；天籁不镜像、拆分或重新发布这些采样。归档 Hash 与完整树
许可与安装说明见
[`VPO 音源许可与安装说明`](../../../../docs/VPO音源许可与安装说明.md)。
