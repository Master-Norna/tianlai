# Tremolo Strings Sample Source

This entry point is pinned to `Strings/all-strings-SEC-tremolo.sfz` from **VPO Standard Orchestra 3.3 / Wave Files 3.2 (2026-06-27)**.

- Upstream: <https://virtualplaying.com/virtual-playing-orchestra/>
- Actual sublibraries: CelloSect, SoloViolin, and ViolinSect from No Budget Orchestra 2, plus VPO `Other/Samples/Bass-Section` and `Other/Samples/Viola-Section`.
- 96 deduplicated WAV files, 84,871,254 bytes, aggregate SHA-256 `b93eb3dc…1389354`.
- The CelloSect/ViolinSect files are marked CC BY-SA 4.0. The SoloViolin license file lists multiple Freesound sources under Sampling+, CC0, CC BY, CC BY-NC, and other terms. Items under `Other` must be checked against the specific SFZ/source documentation.

VPO's general license notice permits music created with the library, including commercial music, but redistribution of the sample library requires source-by-source compliance, attribution, and retention of licenses. Because SoloViolin combines sources under different terms, this project does not redistribute these WAV files in the source release.

Exact hashes for the SFZ, sample collection, licenses, and version evidence are available in [资源核验.json](资源核验.json).
