# 弦乐合奏音源来源

本入口固定使用 **Virtual Playing Orchestra Standard Orchestra 3.3（2026-06-27）** 与 **Wave Files 3.2（2026-06-27）**。

- 上游项目：<https://virtualplaying.com/virtual-playing-orchestra/>
- 实际映射：`all-strings-SEC-sustain/staccato/pizzicato/tremolo/accent.sfz`
- 去重样本：341 个 WAV，合计 200,688,694 bytes
- 主要子库：Sonatina Symphonic Orchestra、No Budget Orchestra、Mattias Westlund、VSCO2 Community Edition，以及 VPO `Other` 整理采样

许可不是单一结论：SSO 标为 CC Sampling Plus 1.0；Mattias/No Budget 文件含 CC BY-SA 4.0；VSCO2-CE 为 CC0；NoBudgetOrch2 的 SoloViolin 许可文件还列出 Sampling+、CC0、CC BY 与 CC BY-NC 等原始来源条款。VPO 总许可说明认为用本库制作音乐（含商业音乐）没有限制，但重新打包/分发采样库必须逐来源保留署名和对应条款，不能只写“VPO 免费”。因此源码包排除这些 WAV，资源安装必须连同上游许可文件保存。

五个 SFZ SHA-256、341 WAV 的逐文件聚合 SHA-256 `56d6b96f…6591bc`、许可与版本证据 Hash 均冻结在 [资源核验.json](资源核验.json)。

安装的固定完整发行树；天籁不镜像、拆分或重新发布这些采样。归档 Hash 与完整树
许可与安装说明见
[`VPO 音源许可与安装说明`](../../../../docs/VPO音源许可与安装说明.md)。
