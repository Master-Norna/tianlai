# String Ensemble Sample Source

This entry point is pinned to **Virtual Playing Orchestra Standard Orchestra 3.3 (2026-06-27)** and **Wave Files 3.2 (2026-06-27)**.

- Upstream project: <https://virtualplaying.com/virtual-playing-orchestra/>
- Actual mappings: `all-strings-SEC-sustain/staccato/pizzicato/tremolo/accent.sfz`
- Deduplicated samples: 341 WAV files, totaling 200,688,694 bytes
- Primary sublibraries: Sonatina Symphonic Orchestra, No Budget Orchestra, Mattias Westlund, VSCO2 Community Edition, and samples curated under VPO `Other`

There is no single license conclusion. SSO is marked CC Sampling Plus 1.0; the Mattias/No Budget files include CC BY-SA 4.0; VSCO2-CE is CC0; and NoBudgetOrch2's SoloViolin license file also lists original sources under Sampling+, CC0, CC BY, CC BY-NC, and other terms. VPO's general license notice states that music made with the library, including commercial music, is unrestricted, but anyone repacking or distributing the sample library must preserve attribution and the applicable terms for every source. It is not sufficient to say only that “VPO is free.” The source package therefore excludes these WAV files, and resource installation must retain the upstream license files with them.

SHA-256 values for all five SFZ files, the per-file aggregate SHA-256 `56d6b96f…6591bc` for the 341 WAV files, and hashes for the license and version evidence are pinned in [资源核验.json](资源核验.json).

The license status of this entry point is `grandfathered`: it only reads a pinned, complete release tree obtained by the installer from VPO's official download chain and installed unchanged. Tianlai does not mirror, split, or republish these samples. Archive hashes and the license and installation notes for the complete tree are available in [`VPO 音源许可与安装说明`](../../../../docs/VPO音源许可与安装说明.en.md).
