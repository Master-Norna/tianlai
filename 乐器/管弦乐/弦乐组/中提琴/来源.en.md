# Viola Section Sample Source

This entry point uses only the Viola Section subset of **VSCO 2 Community Edition**, distributed through the locally installed Virtual Playing Orchestra Wave Files 3.2:

`音源/VirtualPlayingOrchestra/Virtual-Playing-Orchestra3/libs/VSCO2-CE/Strings/Viola Section/`

Runtime loads exactly:

- `susvib/`: 12 sustained-vibrato WAV files.
- `spic/`: 24 short-bow WAV files, comprising 12 root notes × two genuine Round Robins.

`libs/VSCO2-CE/LICENSE.txt` is the full CC0 1.0 Universal text placed with this sublibrary. `Documentation/license.htm` also explicitly associates VSCO 2 Community Edition with CC0 1.0. CC0 does not require attribution, but the project still retains the following source information:

- Original library: Versilian Studios, VSCO 2 Community Edition.
- Local curation/looped version: Virtual Playing Orchestra, Paul Battersby.
- VSCO project page: <https://versilian-studios.com/vsco-community/>.
- VPO page: <https://virtualplaying.com/virtual-playing-orchestra/>.

Runtime does not read the No Budget Orchestra, SSO, Mattias Westlund, Other, or SoundFont resources from the same VPO package. `viola-SEC-sustain.sfz` and `viola-SEC-staccato.sfz` are used only as upstream mapping evidence for numeric root notes, key ranges, offset, panning, and gain. The central mapping `tianlai/vsco2_viola_mapping.py` freezes those facts, and the formal implementation lives in `tianlai/vsco2_viola.py`; neither executes the mixed-license SFZ files. This directory's `VSCO2中提琴映射.py` and `乐器.py` remain only as compatibility wrappers.

[资源核验.json](资源核验.json) records SHA-256 values for all license files, mapping evidence, the central mapping and implementation files named above, and the 36 WAV files, along with their formats, clipping, silence, tails, loop seams, genuine velocity/RR structure, and sampled roots. The source release does not include external WAV files. Installation must preserve the original VPO directory structure and must not copy or rewrite upstream files.
