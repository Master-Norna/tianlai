# Cello Sample Source

The cello uses the solo-cello samples and standard SFZ mappings from **Virtual Playing Orchestra 3.3**.

- Curation and maintenance: Paul Battersby
- Upstream: https://virtualplaying.com/virtual-playing-orchestra/
- Wave package: Virtual Playing Orchestra 3.2 Wave Files
- Mappings: Virtual Playing Orchestra 3.3 Standard SFZ Scripts
- Primary sample sources: No Budget Orchestra, University of Iowa/Other Samples
- Articulations: sustain, normal, staccato, accent, pizzicato

Rendered musical works made with this library may be used commercially. Repacking or redistributing the samples requires retaining appropriate attribution and checking the Creative Commons terms for each source. This project does not place audio assets under source control.

The original README and license files from the upstream archives are retained with the assets under the root-level `音源/` directory. If the samples themselves are distributed in the future, the latest upstream license text must take precedence.

The license status of this entry point is `grandfathered`: the installer obtains only the pinned complete package through VPO's official download chain, extracts it locally without modification, and verifies its 1,922-file tree. Tianlai does not mirror, extract subsets from, or repackage the WAV files. Archive hashes, the installation model, and the six-part review are documented in [`VPO 音源许可与安装说明`](../../../../docs/VPO音源许可与安装说明.en.md).
