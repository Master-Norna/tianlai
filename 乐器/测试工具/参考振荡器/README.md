# 参考振荡器

这是基础乐器层的校准乐器，不模拟真实声学乐器。它提供准确的基频和固定泛音，用于验证：

- A4 基准与十二平均律换算；
- 事件是否落在准确采样位置；
- 复音和延音踏板状态；
- 相同输入是否产生完全相同的 WAV。

每件正式乐器也使用相同的目录约定：

```text
乐器/分类/声部组/乐器名/
├─ 乐器.json       # 元数据、参数和资产映射
├─ 乐器.py         # 该乐器独有的行为，可选
├─ 测试/
└─ README.md
```

没有声部组的类别可以省略该层，例如钢琴位于 `乐器/键盘乐器/钢琴/`。大型音频资产统一放在项目根目录 `音源/`。
