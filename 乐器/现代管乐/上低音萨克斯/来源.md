# 上低音萨克斯音源来源

- 上游仓库：`https://github.com/sfzinstruments/MTG.SoloSax.git`
- 固定提交：`b494d256549b3d088fdec176ce82867f8a1f58b2`（2020-09-19）
- 录音来源：Music Technology Group 在 Freesound 发布的免费萨克斯采样包；上游 README 列出 packs `20251`、`20239`、`20247`、`20253`。
- SFZ 编程、裁切、循环及 FLAC 转换：kinwie；样本规格 24-bit / 48 kHz / mono。
- 许可：Creative Commons Attribution 4.0 International（CC-BY-4.0）。使用或再分发素材时须保留 MTG/kinwie 署名、许可链接及修改说明；完整条款保存在 `音源/MTG-Solo-Sax/LICENSE`。

本入口使用 14 个展开后的 SFZ/数据文件与 230 个 FLAC（26,152,799 bytes）。样本集合 SHA-256 为 `81551f6b647f81c0f50202579bfb7e995e66b5834e2cc493c2f7bd494c450ea9`；许可文件 SHA-256 为 `9ba9550ad48438d0836ddab3da480b3b69ffa0aac7b7878b5a0039e7ab429411`。完整逐文件证据与聚合算法见 [资源核验.json](资源核验.json)，可运行 `核验资源.py` 复算。

GeneralUser GS / TimGM 不参与默认渲染，只能作为用户明确选择的故障后备。
