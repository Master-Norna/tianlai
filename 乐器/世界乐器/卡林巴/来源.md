# 来源

- 上游项目:sgossner/VCSL (Versilian Community Sample Library)
- 原始地址:https://github.com/sgossner/VCSL
- 采用版本:1.2.2-RC
- 固定提交:`b6e6ac82d22248edee98a0bde185eb9ef6d439ad`
- 许可:CC0-1.0(许可证据文件已随资源冻结,见 `资源核验.json` 的 `evidence_sha256`)
- 实际采用文件:1 个 SFZ/包含文件、15 个采样
  (聚合 SHA-256 `6ea996c51ec01f75…`,算法见 `资源核验.json`)
- 本地资源根:`音源/VCSL`；当前为本地冻结副本，由 `资源核验.json` 复算，统一恢复安装链尚未补齐

本项目不修改上游 `Kalimba, Kenya.sfz` 或 WAV，也没有混入替代音源。
`资源核验.json` 额外冻结 15 个 WAV 的逐文件 SHA-256、PCM 格式、时长、尾音、
削波、映射、RR 家族和项目增益余量。文件名中的音名与 SFZ 的 MIDI 八度编号存在
系统性的一八度记谱差异，这是整套资源的命名约定，不能只据文件名把两个高音片
重映射。
