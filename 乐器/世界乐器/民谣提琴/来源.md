# 来源

- 上游项目:Virtual Playing Orchestra 3(Standard 3.3 / Wave 3.2)
- 原始地址:http://virtualplaying.com
- 采用版本:Standard 3.3 / Wave 3.2
- 许可:混合公开许可:SSO Sampling Plus、No Budget Orchestra/Mattias CC-BY-SA、VSCO2 CC0 等,见 Documentation/license.htm(许可证据文件已随资源冻结,见 `资源核验.json` 的 `evidence_sha256`)
- 实际采用文件:4 个 SFZ/包含文件、92 个采样
  (聚合 SHA-256 `42ae0d52908c39cd…`,算法见 `资源核验.json`)
- 本地资源根:`音源/VirtualPlayingOrchestra/Virtual-Playing-Orchestra3`,由带 SHA-256 校验的安装脚本写入 `音源/下载缓存`后解压
- 许可状态：`grandfathered`。只按 VPO 官方完整包原样本机安装并用于音乐渲染；
  天籁不镜像、抽取或重新打包 WAV，依据见
  [`VPO 音源许可与安装说明`](../../../docs/VPO音源许可与安装说明.md)。
- “民谣提琴”是同一小提琴素材的演奏风格入口；`fiddle` 与慢抒情 `sustain`
  共享原始采样，只在天籁清单中使用不同、可复现的包络参数。
