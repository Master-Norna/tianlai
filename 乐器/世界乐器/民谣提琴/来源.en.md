- Upstream project: Virtual Playing Orchestra 3 (Standard 3.3 / Wave 3.2)
- Original URL: http://virtualplaying.com
- Adopted version: Standard 3.3 / Wave 3.2
- License: mixed public licenses including SSO Sampling Plus, No Budget Orchestra/Mattias CC-BY-SA, and VSCO2 CC0; see Documentation/license.htm (the license evidence file is frozen with the resources; see `evidence_sha256` in `资源核验.json`)
- Files actually used: 4 SFZ/include files and 92 samples
  (aggregate SHA-256 `42ae0d52908c39cd…`; see `资源核验.json` for the algorithm)
- Local resource root: `音源/VirtualPlayingOrchestra/Virtual-Playing-Orchestra3`; a SHA-256-verifying installation script writes the download to `音源/下载缓存` and then extracts it
- License status: `grandfathered`. The complete official VPO package is installed locally, unchanged, and used only for music rendering. Tianlai does not mirror, extract, or repackage WAV files; see [`VPO 音源许可与安装说明`](../../../docs/VPO音源许可与安装说明.en.md) for the rationale.
- “Folk fiddle” is a performance-style entry for the same violin material. `fiddle` and the slow lyrical `sustain` share the original samples and differ only through reproducible envelope parameters in the Tianlai manifest.
