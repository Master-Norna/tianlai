# 风笛（formal）

本入口使用 FreePats 2022-12-04 的 G 调风笛实录。上游键盘映射把两根持续低音管
扩展成两个八度，再和旋律管排在同一连续键盘上；这种布局适合通用采样器，却会让
全音域上行试听在约 8 秒和 16 秒出现“换乐器”式硬切。

现在默认入口只演奏和扫描 `chanter`。两根 drone 被拆成独立奏法，并保持各自原始
G2/G3 音高；它们不再伪装成一条可半音移调的旋律音域。

## 音源与许可

- 上游：FreePats Scottish Great Highland Bagpipe，版本 2022-12-04；
- 许可：CC0-1.0；
- 原始文件保留在 `音源/FreePats/Bagpipe`；
- 派生文件写入 `音源/派生/风笛-v1`，许可继承为 CC0-1.0；
- 原始、派生 SFZ、采样和许可证据 Hash 见 `资源核验.json`。

## 离线派生

```powershell
.\.venv\Scripts\python.exe .\乐器\世界乐器\风笛\预处理音源.py
```

脚本读取 `预处理参数.json`，校验原始 SHA-256 后生成：

- `chanter.sfz`：只含 MIDI 64–81 的旋律管；
- `drone-low.sfz`：只在 MIDI 43 触发原始低音 drone；
- `drone-high.sfz`：只在 MIDI 55 触发原始高音 drone；
- F4、G4 两组离线派生 WAV；
- 可复核的 `处理说明.json`。

F4、G4 派生样本的稳态 RMS 统一到 −13.3 dBFS，SFZ 对三者统一补偿 2 dB；
G4 的两次真实 RR 分别使用温和高频搁架，使 F4→G4 接缝不再发生过大的亮度突变。
采样率、帧数、循环点和上游 tune 均保持不变。

## 奏法与音域

- `chanter`：默认，E4–A5（MIDI 64–81）；
- `drone_low`：G2（MIDI 43）；
- `drone_high`：G3（MIDI 55）。

完整风笛乐句应先分别启动两个 drone，随后切回 `chanter` 演奏旋律，并让 drone
跨乐句持续；切换奏法不会终止已经保持的声音。这样得到的是两根持续管加旋律管的
同一件乐器，而不是把三个部件依次当成半音音阶。

## 已知限制

旋律管仍是单力度层，只有大部分根音具备两次 RR。派生匹配只修复已确认的 F4/G4
接缝，不用激进均衡掩盖其他录音差异。新的全音域和组合乐句试听仍需人工复核。
