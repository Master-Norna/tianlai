# 日本筝(formal,确定性建模)

扩展 Karplus-Strong 筝模型:洁净拨弦、桐木共鸣体、中长延音。实现位于 `tianlai/modeled_instruments.py`(profile
`koto`,引擎 1.1.0),显式种子 41004,同一事件
序列必得同一输出;不含通用 SoundFont 静默回退。

## 建模缘由(诚实声明)

未找到有明确公开许可的真实采样,先以确定性物理建模补位;真实采样仍是后续保真升级方向。

## 来源与许可

项目自研确定性 DSP;引擎源文件 SHA-256 与全部参数见
[`资源核验.json`](资源核验.json),复算脚本 [`核验资源.py`](核验资源.py)。

## 音域

D3(50) - E6(88)

## 调音

自测校准:渲染 3 个探测音并 FFT 实测,最大误差 0.019 音分(详见 [`音准校准.json`](音准校准.json))

## 试听

固定事件:`examples/日本筝_奏法.events.json`;
渲染 11.89 s,峰值 0.257969,
RMS 0.047801,削波 0;
WAV SHA-256 `eb1f9907…`。复算脚本 [`核验试听.py`](核验试听.py)。

## 已知限制

确定性弦模型非实录;无义甲刮奏/压弦滑音奏法。当前绑定版本已通过单音色试听并标为 formal；协奏、完整奏法与实际曲目仍未测试。
