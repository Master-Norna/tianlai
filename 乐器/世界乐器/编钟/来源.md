# 来源与权利说明

本目录的 `乐器.py` 是天籁项目自研代码；运行时不读取采样、脉冲响应、
SoundFont、SFZ 或其他外部音频资源。`资源核验.json` 会冻结实现文件的
SHA-256，并明确登记外部资源数组为空。该实现按照仓库根目录的
Apache License 2.0（Apache-2.0）发布；结构化来源声明同时确认它是项目自研 DSP，
不含第三方采样或其他外部音频资产。

模型采用公开声学常识层面的假设：椭圆截面双音钟具有随击位变化的两组
非谐模态，辐射损耗使低音钟衰减普遍长于高音钟。当前模态比例和衰减曲线
只作为“代表性现代双音钟”的建模参数，不归因于、也不声称测量复刻曾侯乙
编钟或任何其他特定馆藏。

建模前查阅的公开资料如下，仅用于确认双音、击位与非谐模态等声学方向：

- [湖北省博物馆：曾侯乙编钟藏品介绍](https://m-www.hbww.org.cn/p/4695.html)
- [深圳博物馆：编钟正鼓部、侧鼓部击奏说明](https://www.shenzhenmuseum.com/webCollection/collectionDetail?lmType=L0303&resId=b184e070c4ed4df6bb77780a1e5bb8b7)
- [Acoustical Society of America：亚洲钟的杏仁形截面与模态成对现象](https://acoustics.org/pressroom/httpdocs/147th/Rossing_AsianBells2.htm)
- [JASA / PubMed：双音钟截面与两音关系的理论研究摘要](https://pubmed.ncbi.nlm.nih.gov/14514215/)

没有从这些资料复制音频、程序代码或逐钟测量数据；本项目中的模态表、
衰减曲线、瞬态和立体声参数均为项目自行设计的代表性合成参数。

第一版主动省略了房间混响、近频强失谐对、LFO 和左右声道失谐。这样既
避免用长混响冒充钟体，也降低持续拍频被听成电流声的风险。弱的另一击位
模态族保持短且轻；抗混叠滤波从采样率的 0.34 倍连续衰减，到 0.45 倍
完全归零。
