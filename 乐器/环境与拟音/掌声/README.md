# 掌声

`formal` 群体掌声模型：确定性调度大量左右散布的短促手掌微脉冲，并叠加低电平人群底噪；不是一枚 GM 掌声样本循环。

- `modulation` 连续控制拍手密度，力度和 `expression` 控制整体响度，`distance` 控制听距。
- `note_on` 开始人群，`note_off` 让密度自然淡出；延音踏板可延迟结束。
- 固定种子确保同一事件文档可重复，改变种子可得到另一组人群时序。
- 当前绑定版本的单音色/单场景试听已通过，因此为 `formal`；真实场馆早期反射、个体手型、欢呼层与协奏语境仍待审。
