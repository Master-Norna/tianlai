# 呼吸噪声

`formal` 程序建模：独立左右湍流噪声经呼吸带宽与声道共振塑形，并以缓慢呼吸脉动调制，不再加载 GM 占位音色。

- `note_on` 开始气流，`note_off` 呼气式淡出；力度控制初始气流。
- `expression` 控制电平，`modulation` 改变气道共振，`distance` 控制距离衰减，支持延音踏板。
- 固定种子保证重复渲染逐样本一致；该非定音乐效主动忽略 MIDI 音高。
- 当前绑定版本的单音色/单场景试听已通过，因此为 `formal`；当前不建模真人
  吸气/呼气相位、口鼻切换、性别或近讲实录，协奏语境仍为 `untested`。
