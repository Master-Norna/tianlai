# Synthesized rainy ambience

A `formal` procedural rain environment: a broadband rain curtain, a
low-frequency roof/distant-field component, and stereo raindrop resonances
scheduled from a fixed seed create a seamless sustained ambience.

- `modulation` controls raindrop density, velocity/`expression` control rain intensity, and `distance` controls distance attenuation.
- `note_on` starts the rain environment and `note_off` applies a long fade; identical events reproduce it sample by sample.
- The currently bound version has passed single-instrument/single-scene listening review and is therefore `formal`. It does not yet distinguish windows, leaves, car roofs, or standing water and includes neither thunder nor a recorded spatial response; long-loop ensemble and extended-duration contexts still await review.
