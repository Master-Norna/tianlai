# Bird chorus

A `formal` bird-community model: a fixed seed schedules FM calls with varying
directions, durations, and upward/downward frequency sweeps, over extremely
low-level woodland air noise.

- `modulation` controls call density, velocity/`expression` control community loudness, and `distance` controls listening distance.
- `note_on` starts the community and `note_off` fades it out; the same seed and events produce exactly the same bird-call timeline.
- The currently bound version has passed single-instrument/single-scene listening review and is therefore `formal`. This is a generic synthesized bird community and does not impersonate a particular species, season, or region; species-level identity and long-duration ensemble use remain known boundaries.
