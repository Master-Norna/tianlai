# 枪声

`formal` 一次性冲击模型：枪口压力脉冲、宽带爆音、低频膛口共振、机械尾声和三组离散反射共同构成自然尾音。

- `note_on` 触发完整 2.4 秒模型；早到的 `note_off` 不会截断一次性冲击。
- 力度/`expression` 控制能量，`distance` 控制距离衰减；固定种子使噪声与反射完全可复现。
- MIDI 音高不改变枪声，避免把非定音冲击误当旋律乐器。
- 当前绑定版本的单音色/单场景试听已通过，因此为 `formal`；这是通用声学模型，不代表具体枪械、口径、抑制器或真实空间，身份与协奏语境仍待审。
