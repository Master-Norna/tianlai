# 羽管键琴（formal）

VCSL 佛兰芒羽管键琴，接入 8′、4′ 和两者联用的 full 三种音栓。本目录是
98 项清单 SAM-49 的专用实现，渲染引擎复用 `tianlai/dedicated_sfz.py`，
资源缺失时直接报错，不会静默回退到通用 SoundFont。

## 来源与许可

- 上游：sgossner/VCSL（Versilian Community Sample Library）。
- SFZ 发布版：`v1.2.2-RC`，对应提交
  `b6e6ac82d22248edee98a0bde185eb9ef6d439ad`。
- 许可：CC0-1.0；冻结的上游 `README.md` 明确声明整套资源为 CC0。
- 逐文件 SHA-256、格式与区域统计见 [`资源核验.json`](资源核验.json)，
  复算脚本为 [`核验资源.py`](核验资源.py)。

## 映射、奏法与实际音域

| 奏法 | SFZ | 按键 / 乐谱输入 | 实际发声 |
| --- | --- | --- | --- |
| `eight_foot` | `Harpsichord, Flemish - 8'.sfz` | F1–C6（29–84） | F1–C6，同音 8′ |
| `four_foot` | `Harpsichord, Flemish - 4'.sfz` | F1–C6（29–84） | F2–C7，比按键高 1 八度 |
| `full` | `Harpsichord, Flemish - Full.sfz` | F1–C6（29–84） | 每键同时触发 8′ 同音与 4′ 高八度 |

默认奏法是 `full`，`pitch_mode` 为 `pitched`。三份上游 SFZ 均连续覆盖全部
56 个按键；8′ 使用 28 个离散采样根，4′ 使用 26 个离散采样根，full 在每键
叠加两套映射。每套持续音均有对应的真实释键采样。

清单另声明 `calibration_articulation: eight_foot`：通用逐键音准巡检应选用
单一同音音栓，避免 full 中真实存在的 4′ 高八度分量压过 8′ 基频而被算法误报
成整八度映射错误；专属校准报告仍会分别检查全部 8′、4′ 根采样。

## 调音与资源质量

54 个持续根采样按音栓的**实际发声音高**重新测量。8′ 以按键音为目标，4′ 以
按键上方 1200 cents 为目标；总体中位残差 -1.227 c，最大绝对残差 8.293 c。
旧报告的 135.404 c 不是坏 E5，而是把 4′ 样本误按键盘原八度做窄窗 FFT 后抓到
了无关低频谱峰。逐样本与分音栓结果见 [`音准校准.json`](音准校准.json)。

采用资源是 44.1 kHz、24-bit、双声道 WAV。持续采样保留 2.658–17.413 秒的
自然衰减，没有伪造 WAV/SFZ 循环；释键采样为 0.636–1.869 秒。资源共 108 个
唯一 WAV，三种奏法合计引用 108 个持续区域和 108 个释键区域。

## 试听

固定事件为 `examples/羽管键琴_奏法.events.json`，覆盖低/中/高按键、长短音、
三种音栓与释键。机器核验指标和当前 WAV/manifest/events Hash 见
[`试听核验.json`](试听核验.json)，可用 [`核验试听.py`](核验试听.py)复算。

## 已知限制

- 原始资源只有一个录音力度和一个变体，没有音色力度层或 RR；当前速度只控制
  增益，不应被表述成真实的弱/中/强采样。
- 未接入鲁特音栓，也没有独立的 8′/4′ 音栓平衡控制。
- full 的复合频谱在个别按键可能由 4′ 分量占优；这属于双音栓音色，不应让
  单音高算法把它当成按键整体错高八度。
- 本次完成机器音准、全音域映射、释放、Hash 和削波核验；人工盲听仍为
  `pending`，因此只阻断相应严格能力声明；当前绑定版本的单音色状态仍为 formal，协奏未测试。
