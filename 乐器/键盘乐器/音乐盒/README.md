# 音乐盒(formal,确定性建模)

音乐盒钢梳齿模型:非谐分音(1/3.42/8.93 倍)、快衰减、轻机械触点。实现位于 `tianlai/modeled_instruments.py`(profile
`music_box`,引擎 1.1.0),显式种子 41051,同一事件
序列必得同一输出;不含通用 SoundFont 静默回退。

## 建模缘由(诚实声明)

发声机理适合建模;真实采样对照仍是后续保真升级方向。

## 来源与许可

项目自研确定性 DSP;引擎源文件 SHA-256 与全部参数见
[`资源核验.json`](资源核验.json),复算脚本 [`核验资源.py`](核验资源.py)。

## 音域

C5(72) - G7(103)

## 调音

自测校准:渲染 3 个探测音并 FFT 实测,最大误差 0.024 音分(详见 [`音准校准.json`](音准校准.json))

## 试听

固定事件:`examples/音乐盒_奏法.events.json`;
渲染 11.89 s,峰值 0.415550,
RMS 0.102922,削波 0;
WAV SHA-256 `8c66c99e…`。复算脚本 [`核验试听.py`](核验试听.py)。

## 已知限制

确定性模型非实录;无发条机构走带噪声循环。当前绑定版本已通过单音色试听并标为 formal；协奏、完整奏法与实际曲目仍未测试。
