# 来源

- 上游项目：Greg Sullivan E-Pianos，Yamaha CP80 Electric Grand Piano
- 原始地址：https://github.com/sfzinstruments/GregSullivan.E-Pianos
- 采用版本：`8c3e581acda3594b553948ff0222d4f84a698376`
- 许可：[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)；Greg
  Sullivan 提供原始录音，kinwie 完成 SFZ/FLAC 映射。许可证全文与 README
  均冻结在 `资源核验.json`。
- 采用 `CP80/CP80.sfz` 及其四档力度 FLAC；资源统计与聚合 Hash 由 `核验资源.py` 复算。
- 资源与电钢琴入口共享；固定提交的无覆盖安装及许可证/样本校验由 [`../获取GregSullivan电钢琴音源.ps1`](../获取GregSullivan电钢琴音源.ps1) 完成。
- 效果链为项目自研确定性 DSP（`tianlai/dedicated_fx.py`），参数固化于 `乐器.json`。
- 上游 SFZ 与 FLAC 字节保持不变。天籁先用自研确定性带限重采样器输出 48 kHz，
  再应用立体声 chorus；署名、许可证链接与两项修改说明由 `乐器.json` 进入许可
  旁车。
- 旧版 VCSL TX81Z FM Piano 因整件低一八度已停止使用。
