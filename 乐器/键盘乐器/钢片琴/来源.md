# 钢片琴音源来源

本入口固定使用 **Virtual Playing Orchestra Standard Orchestra 3.3（2026-06-27）** 与 **Wave Files 3.2（2026-06-27）**。

- 上游项目：<https://virtualplaying.com/virtual-playing-orchestra/>
- 实际映射：`Keys/celesta.sfz`
- 实际资源：20 个去重 WAV，合计 25,886,804 bytes
- 原始录音：Freesound 用户 `stamperadam` 的 Celesta pack
- 原始许可：`Creative Commons Zero 1.0`；证据文件为 `libs/stamperadam/samples/celesta/_readme_and_license.txt`

VPO 总许可说明与 Celesta 原始许可文件的 SHA-256 均冻结在 [资源核验.json](资源核验.json)。20 WAV 的逐文件聚合 SHA-256 为 `d6dcdc07facb387ade3f40fcd0132c94b58450477599e20e676e086e75b504dd`。源码发布包不复制这些 WAV，安装资源时应保留上游许可与版本文件。
