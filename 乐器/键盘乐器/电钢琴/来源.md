# 来源

- 上游项目：Greg Sullivan E-Pianos，Yamaha CP80 Electric Grand Piano
- 原始地址：https://github.com/sfzinstruments/GregSullivan.E-Pianos
- 采用版本：`8c3e581acda3594b553948ff0222d4f84a698376`
- 许可：[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)；Greg
  Sullivan 原始录音，kinwie 完成 SFZ/FLAC 映射。许可证全文与 README 均列入
  `资源核验.json` 的证据 Hash。
- 采用 `CP80/CP80.sfz` 及其四档力度 FLAC。资源数量、格式和聚合 SHA-256 由 `核验资源.py` 复算，不能手填。
- 本地资源根：`音源/GregSullivan.E-Pianos`；大型采样不进入轻量源码发布包。
- 共享安装器：[`../获取GregSullivan电钢琴音源.ps1`](../获取GregSullivan电钢琴音源.ps1)。它只检出固定提交并校验 SFZ、81 个样本、许可证和上游 README；若目标目录已经存在，则验证后退出，绝不覆盖。
- 上游 SFZ 与 FLAC 字节保持不变。天籁的修改是使用自研确定性带限重采样器解释
  该映射并输出 48 kHz 音频；署名、许可证链接与修改说明写入 `乐器.json`，随
  实际渲染进入许可旁车。
- 旧版 VCSL TX81Z FM Piano 因上游根音映射导致整件低一八度，且只是 FM 电子补位音色，已停止作为本入口默认资源。
