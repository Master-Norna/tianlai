# Source

> This English translation is provided for reference only. The original
> upstream license and evidence take precedence.

- Upstream project: Greg Sullivan E-Pianos, Yamaha CP80 Electric Grand Piano
- Original URL: https://github.com/sfzinstruments/GregSullivan.E-Pianos
- Adopted version: `8c3e581acda3594b553948ff0222d4f84a698376`
- License: [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/);
  original recordings by Greg Sullivan, with SFZ/FLAC mapping by kinwie. The
  full license and README are included in the evidence Hash in
  `资源核验.json`.
- Uses `CP80/CP80.sfz` and its four velocity levels of FLAC files. Resource count, format, and aggregate SHA-256 are recomputed by `核验资源.py` and must not be entered manually.
- Local resource root: `音源/GregSullivan.E-Pianos`; large samples are excluded from the lightweight source release package.
- Shared installer: [`../获取GregSullivan电钢琴音源.ps1`](../获取GregSullivan电钢琴音源.ps1). It checks out only the pinned commit and verifies the SFZ, 81 samples, license, and upstream README. If the target directory already exists, it verifies and exits without ever overwriting it.
- The upstream SFZ and FLAC bytes remain unchanged. Tianlai's modification is
  to interpret that mapping through its project-authored deterministic
  band-limited resampler and emit 48 kHz audio. Attribution, the license link,
  and this change notice are recorded in `乐器.json` and flow into the license
  sidecar for an actual render.
- The former VCSL TX81Z FM Piano is no longer the default resource for this entry because its upstream root mapping made the entire instrument one octave too low and it was only an electronic FM substitute.
