# 击弦古钢琴（formal）

本入口采用德国国立音乐研究所（SIMPK）乐器博物馆收藏的一台 Johann Gottlob
Horn 击弦古钢琴实录，乐器约制于 1793 年。它替换了上一版 VCSL TX81Z
Clavisynth 电子近似音色；渲染引擎继续复用 `tianlai/dedicated_sfz.py`，不会
静默回退到 General MIDI。

## 安装

```powershell
.\乐器\键盘乐器\击弦古钢琴\获取音源.ps1
```

安装器固定 SIMPK 1.0 原始归档，先校验体积、SHA-256、许可证、原始
`clavichord.dspreset` 和全部 WAV，再在临时目录中生成本项目 SFZ；已有目标目录
只复核，不覆盖、不合并。大型资源只进入根目录 `音源/`，轻量发布包不包含它。

## 来源与许可

- 原作者/应署名者：Staatliches Institut für Musikforschung（SIMPK）；
- 实物：Johann Gottlob Horn clavichord，Dresden，约 1793；
- 上游版本：`SIMPK_03_Clavichord` 1.0；
- 许可：CC BY 4.0；
- 本项目改动：把上游 DecentSampler 映射确定性转换为 SFZ，将高一个八度的
  `rootNote=40–102` 标签按实测原音映射到 MIDI 28–90，并依据逐样本测量写入
  细调；原 WAV 不做升八度、降噪、压缩或波形改写。

正式来源、归档摘要和内容去重证据见 [`来源.md`](来源.md) 与
[`SIMPK来源证据.json`](SIMPK来源证据.json)；安装后的逐文件冻结结果见
[`资源核验.json`](资源核验.json)。

## 音域、力度与轮替

- 上游预设把根音标成 E2–F#7（MIDI 40–102），但音高复核显示录音实际低一个
  八度；本项目保留原生音高，正式可演奏音域为 E1–F#6（MIDI 28–90）；
- 63 个半音都有独立根采样，不跨键拉伸；
- 归档有 756 条 WAV 映射路径，但解码 PCM 只有 252 份唯一内容：
  `2 音色 × 63 键 × 2 RR = 252`；
- 每个“音色 × 键 × RR”组中的 3 个上游力度文件 PCM 完全相同，因此只有
  **1 个真实实录力度**。转换器保留 3 个上游力度映射区用于兼容和确定性路由，
  不能把它们称为 3 个真实力度层；
- 输入力度仍可通过增益响应改变音量，但不会切换到不同的实录音色动态；
- 每键、每音色有 2 路 Round Robin；PCM 去重未发现跨 RR、跨键或跨音色复用；
- 无伪造循环，沿用自然衰减及上游采样边界，note-off 使用 4 秒释音。

## 奏法

- `normal`：上游 `lupe` 组，默认主音色；
- `resonance`：上游 `reso` 组，共鸣取向的独立实录集合。

两组不是叠加触发；协作层用 `articulation` 事件显式切换。

## 当前级别

资源来源、许可、键位、真实力度数、RR、Hash、自动音准和 Windows 中文路径均须
通过机器门禁。历史乐器本身的机械噪声和音色差异会保留，不以“去噪”抹平。人工
当前绑定版本的单音色试听已通过，因此标记为 `formal`；完整资源盲听与协奏仍待审，不能声称 100% 还原。
