# Piano sound-source provenance

> This English translation is provided for reference only. The original
> upstream license and evidence take precedence.

The first piano uses **Salamander Grand Piano V3**:

- Original author: Alexander Holm
- Instrument: Yamaha C5
- Recording: 48kHz / 24-bit, AKG C414 AB stereo
- Content: 16 velocity layers, hammer-release sounds, three layers of string-resonance release sounds, and pedal mechanical sounds
- License: Creative Commons Attribution 3.0 Unported (CC BY 3.0)
- License URI: https://creativecommons.org/licenses/by/3.0/
- Upstream: https://github.com/sfzinstruments/SalamanderGrandPiano
- Pinned commit: `3382bf9496bba2486f5ab0de55a264d1dfc38404`

Audio assets are excluded from this project's code version control. Any
release containing these samples or derivatives must retain the author's
attribution and the license text.
Tianlai does not rewrite the upstream FLAC files. Rendered audio passes through
a custom sample map, the C8 real-pitch declaration, the performance state
machine, and band-limited resampling; the adjacent licence sidecar retains this
modification notice and the licence URI.

[`获取音源.ps1`](获取音源.ps1) does not follow a moving upstream branch and
fetches only the commit above. It verifies the following supply-chain evidence
in a temporary directory before atomically switching the formal directory. The
old directory is restored automatically if switching fails:

- Complete working tree (excluding `.git/`): 668 files, 748,451,483 bytes; aggregate SHA-256 `FCF5B194A5E19057F006138F7EC852C0B1354E12D65C8250546F9CDB5CBDDB82`.
- All 641 upstream FLAC files: 748,397,030 bytes; aggregate SHA-256 `1FA0E381904391B759CB3E82FF60BC54716AD99FD30ED07FD49C2128EF6239E5`.
- `LICENSE`: `E6BC9E9C474700B708F568BAC9E5A8A9BCB2B1DAD53442F5BA449FCB848B8E76`.
- `README.md`: `BE275B843D10A22E614E5F52BD414FE2CBDCBFD6165894B1DCCA738E8CBF391A`.
- Main SFZ: `C8B282F03FDB2D9E6BE24A99DF0D97A05E7ECE718D1A14E0B882C518161F7837`.

The tree-digest algorithm matches the sample-digest algorithm in
[`资源核验.json`](资源核验.json): sort by relative-path ordinal, write one line
per file as lowercase `<file SHA-256>  <forward-slash relative path>\n`, then
compute SHA-256 over the UTF-8 records. This verifies the current local tree
without mistaking “downloadable from a repository with the same name” for
“still the pinned, verified version.”

The complete upstream tree contains 641 FLAC files, and Tianlai now maps all of
them at runtime: 480 main-note samples, 88 key-release mechanical sounds, three
sets of 23 string-release resonances, and 4 pedal mechanical sounds. The third
`harmV3*.flac` set does not replace `harmS` / `harmL`; it plays in parallel on
key release with the S / L layer selected by velocity. Every piano sample path
uses versioned band-limited resampling, with a direct bypass when the playback
step is exactly `1:1`.

Upstream also provides an optional sample-start offset for faster touch
response. Tianlai preserves the full attack by default and does not enable
that optional fast-response mode in this refinement. Sympathetic resonance is
still represented by the release samples above; it is not a physical model of
coupling among strings.

The tuning report analyzes only pitched main-note samples and the three
string-release-resonance layers. Unpitched key-release and pedal mechanical
sounds do not participate in tuning statistics or conclusions. Although the
upstream files are named `C8v*.flac`, the recordings measure as C#8. Runtime
mapping already declares their real pitch as `+100 cents` and maps B7 / C8
correctly; this is not an unresolved C8 defect.
