# 钢琴

基于 Salamander Grand Piano V3 的 Yamaha C5 三角钢琴。

## 当前能力

- 30 个采样根音覆盖 A0–C8；
- 保留上游 SFZ 的 16 个非均匀力度层；
- 按需解码 FLAC，不在启动时载入整套音源；
- 运行时完整使用上游 641 个 FLAC：480 个主音、88 个释键机械声、69 个琴弦
  释放共鸣和 4 个踏板机械声；
- 88 键独立释键机械声；
- 三层琴弦释放共鸣：`harmS` / `harmL` 按力度选择，`harmV3` 与所选层并行释放；
- 延音踏板状态和两组踏板升降机械声；
- 无制音器高音区使用更长的释放时间；
- 柔音踏板的首版近似响应；
- 全部钢琴采样通路使用版本化带限重采样；播放步进恰为 `1:1` 时直接旁路，
  避免无意义地改变原采样；
- 采样点精确调度和确定性采样选择。

## 当前限制

- 半踏板目前连续接收数值，但制音切换仍以阈值近似；
- 交感共鸣使用上游释放采样，不是全局琴弦耦合模型；
- 柔音踏板尚无独立采样层；
- 上游提供以采样起点偏移换取更快触键响应的可选模式；本入口默认保留完整起音，
  本轮不启用该可选快速响应；
- 尚未实现重新踩踏、中央踏板和音板物理模型。

授权及音源来源见 [来源.md](来源.md)。

## 音准验证

实际测量中层力度 A4：

```powershell
.\.venv\Scripts\python.exe -m tianlai analyze-pitch `
  --audio 音源/钢琴/SalamanderGrandPiano/Samples/A4v8.flac `
  --expected-hz 440
```

当前结果约为 `440.2334 Hz / +0.918 cents`，专项测试要求误差小于 2 音分。

本入口为 `formal`。核验材料：

- [`资源核验.json`](资源核验.json)：构造实例后遍历**实际映射**的 641 个采样并逐文件

- [`试听核验.json`](试听核验.json)：88 键全音域压力扫描的峰值/RMS/削波/WAV 哈希；

## 采样映射说明

### C8 组采样

上游 `C8v*.flac` 实测约为 C#8。中央实现 `tianlai/piano.py` 的
`_ROOT_TUNING_CENTS` 将该组根
采样声明为 `+100 音分`，引擎据此把 B7 / C8 键重采样回正确音高。这项校准已经
生效，不是仍待修复的 C8 缺陷；其他根采样不做这项修正，以保留钢琴原有的伸展
调律。完整测量见 [`音准校准.json`](音准校准.json)。

### 不是缺陷：高音区 +27～+38 音分

F7–B7 一带测得约 +27～+38 音分，属于钢琴的 Railsback 伸展调律：高音区偏高、
低音区偏低。它不是平均律误差，渲染不会把这一区域强制拉平。

### 其他

- 释键噪（`rel*.flac`）与踏板噪（`pedal*.flac`）为无调性的机械层；音准报告不再
  尝试为它们推导基频，也不把它们纳入音准统计或结论。
- 当前报告纳入 480 个主音和 69 个有根音映射的琴弦释放共鸣。主音中位偏差
  `+0.766 音分`、最大绝对偏差 `41.125 音分`，没有超过 50 音分的主音离群点；
  报告中的 6 个大离群点全部来自非稳态共鸣释放采样，应按路径单独听审，不能据此
  自动重调主钢琴。
