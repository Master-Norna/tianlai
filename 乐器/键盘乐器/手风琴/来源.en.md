# Source

> This English translation is provided for reference only. The original
> upstream license and evidence take precedence.

- Upstream project: FreePats project: Button Accordion HN
- Official page: <https://freepats.zenvoid.org/Organ/accordion.html>
- Source/resource repository: <https://github.com/freepats/button-accordion-HN>
- Release version: 2024-03-29 (the resource README marks production version 2024-03-21)
- License: CC0-1.0
- License evidence: `LICENSE.txt` and `README.txt` at the resource root
- Actually adopted: 1 SFZ, 17 attack FLAC files, and 17 paired release FLAC files
- Local resource root: `音源/FreePats/ButtonAccordionHN`
- Download archive: `音源/下载缓存/ButtonAccordionHN-SFZ+FLAC-20240329.7z`

License evidence, mapping, and SHA-256 values for the 34 samples actually used
at runtime are frozen in [`资源核验.json`](资源核验.json). The program does not
read a SoundFont, synthesized sound, or other accordion recording outside the
same resource root.

No other accordion or synthesized resource is mixed in. No more suitable
public source has yet been found that simultaneously provides a real accordion,
root notes above MIDI 79, suitability as a sustained instrument, a
CC0/CC-BY-3.0/CC-BY-4.0 license, and freezable evidence. MIDI 50–79 is therefore
the core range, 80–82 is only a limited transposed extension, and MIDI 83–91 is
explicitly rejected.
