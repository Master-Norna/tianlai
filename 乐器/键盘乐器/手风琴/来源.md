# 来源

- 上游项目：FreePats project: Button Accordion HN
- 官方页面：<https://freepats.zenvoid.org/Organ/accordion.html>
- 源码/资源仓库：<https://github.com/freepats/button-accordion-HN>
- 发布版本：2024-03-29（资源内 README 标记制作版本 2024-03-21）
- 许可：CC0-1.0
- 许可证据：资源根的 `LICENSE.txt` 与 `README.txt`
- 实际采用：1 个 SFZ、17 个攻击 FLAC、17 个配对释放 FLAC
- 本地资源根：`音源/FreePats/ButtonAccordionHN`
- 下载归档：`音源/下载缓存/ButtonAccordionHN-SFZ+FLAC-20240329.7z`

许可证据、映射与 34 个实际运行样本的 SHA-256 已冻结在
[`资源核验.json`](资源核验.json)。程序不会读取同一资源根之外的
SoundFont、合成音或其他手风琴录音。

当前没有混入其他手风琴或合成资源：尚未找到同时满足“真实手风琴、根音高于
MIDI 79、可作为持续乐器、采用 CC0/CC-BY-3.0/CC-BY-4.0 且证据可冻结”的
更合适公开资源。因此 MIDI 50–79 为核心音域，80–82 仅作有限移调扩展，
MIDI 83–91 明确拒绝。
