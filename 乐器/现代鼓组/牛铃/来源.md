# 牛铃音源来源

本入口固定使用 **Virtual Playing Orchestra Standard Orchestra 3.3（2026-06-27）** 与 **Wave Files 3.2（2026-06-27）**。

- 上游项目：<https://virtualplaying.com/virtual-playing-orchestra/>
- 实际映射：`Percussion/misc.sfz` 中 G♯3 / MIDI 56 的 Cowbell 区域
- 实际资源：4 个去重 WAV，合计 381,182 bytes
- 原始子库：VSCO2 Community Edition
- 原始许可：CC0 1.0；证据为 `libs/VSCO2-CE/LICENSE.txt`

SFZ、许可与版本证据 Hash 均冻结在 [资源核验.json](资源核验.json)。4 WAV 的逐文件聚合 SHA-256 为 `ec6a144725440bc2bc0e75543a923bf6e5c78783921203544069d2469304dacb`。
